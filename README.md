# VoxePrint

**Calculator and management system for 3D printing**

Desktop software for 3D printing enthusiasts and small businesses. Generate quotes, manage clients, filaments and printers — all from a local app with no subscriptions or cloud required.

---

## Features

- **Quote generation** — calculate costs based on filament, time, electricity, post-processing and margins
- **G-Code parsing** — import `.gcode` files to extract print time and weight automatically (OrcaSlicer, PrusaSlicer, Creality Print, Bambu Studio)
- **Client management** — store client data with regional tax ID support (RUC, CUIT, NIT, CPF, RFC, etc.)
- **Filament inventory** — track rolls, weight, price per gram and usage
- **Printer management** — multiple printers with individual cost configurations
- **PDF export** — professional quote documents and statistics reports
- **Price note** — quick printable summary without full PDF generation
- **Advance payment** — configurable automatic advance modes by amount thresholds
- **Multi-currency** — supports currencies across Latin America, US, EU and more
- **Multi-language** — Spanish, English and Portuguese; community language packs via ZIP
- **Regional localization** — date formats and tax ID labels adapt to the configured region
- **Dark / Light / Auto theme**
- **Auto-update check** — configurable frequency
- **Local SQLite database** — no internet, no cloud, no subscriptions

---

## Requirements

- Windows 10 / 11 (64-bit)
- Python 3.11+ *(if running from source)*

## Running from source

```bash
pip install -r requirements.txt
python app.py
```
